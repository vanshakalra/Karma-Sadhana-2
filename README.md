# Karma Sadhana – landing page prototype

Static site (HTML + CSS + JS). No build step.

## Run locally
    npx serve .        # or: python3 -m http.server 8080

## Deploy on Vercel
- Framework Preset: **Other**
- Build Command: *(empty)*
- Output Directory: *(empty / root)*
- Root Directory: the folder containing index.html

## Notes
- Fedra fonts are embedded in fonts.css (base64). Replace with licensed webfonts before public launch.
- Forms are prototype only; nothing is sent.
